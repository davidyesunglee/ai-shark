# AI Shark customer appeal and retention plan

## Objective
Help an owner with an existing business plan understand the value of a documentation review, try it with informed consent, and return to review meaningful revisions. Do not equate a document score with loan approval.

## Implementation strategy
1. Rebuild the public offer and presentation in the existing React application: homepage, pricing, and fictional sample report. Preserve live catalog and checkout behavior.
2. Align free-preview, paid-report, and privacy explanations with actual processing. Remove unverifiable testimonials and unsupported financing predictions.
3. Improve the report-to-revision journey using existing recommendations, assessment history, credits, and upload flow. Do not require a schema migration or new subscription.
4. Verify type checking, production build, responsive presentation, and links. Do not submit paid AI requests, charge cards, or alter production customer data for verification.
5. Publish only through the owner's explicit publishing action; workspace changes are not automatically live.

## Commercial recommendations, not changes to billing
- Test a non-recurring initial-review-plus-revision package with customers before creating a new Stripe product.
- Keep existing prices, entitlements, subscriptions, and cancellation access intact.
- Prioritize borrowers approaching a lender. Treat students as a separate segment to research rather than dilute the core offer.
- Interview advisors about repeated client reviews before building firm accounts or volume workflows.

## Next product investments
- Trace recommendations to actual source passages and show financial calculation inputs. This requires analyzer and report-contract work; do not claim it already exists.
- Validate scoring consistency and obtain qualified review of the rubric before claiming underwriting authority.
- Collect permission-based case studies about documentation improvements, not guaranteed financing outcomes.

## Measurement
Compare free-preview completions, paid conversions, second evaluations, renewals, cancellations, and customer-reported usefulness. Segment one-project owners from repeat-review advisors. Do not claim uplift before collecting evidence.

## Boundaries
No hosting migration, automatic publishing, payment changes, customer-data migration, or new email automation. The separately requested Sunday email schedule remains a separate blocked deployment concern.
